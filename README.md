# ThermoLogger

熱電対の温度を取得し、経過時間とともにシリアル出力および小型OLEDディスプレイへ表示する温度ロガー装置です。

---

## 概要

本装置は、熱電対アンプ IC（MAX31855）を用いて測定した温度データを約1秒周期で取得し、USBシリアル通信（CSV形式）で出力すると同時に、I2C接続の小型OLEDディスプレイにリアルタイム表示します。
外部タクトスイッチを押下することで、経過時間（タイムスタンプ）をいつでもゼロリセットすることが可能です。

---

## 主な機能

* **熱電対による温度測定**
  * MAX31855 アンプモジュールを使用し、摂氏温度（℃）を取得。
  * 熱電対の断線（オープン）、GNDショート、VCCショートの異常検知およびエラー表示に対応。
* **OLEDディスプレイ表示**
  * 0.91インチ（128×32ドット）OLEDに現在の温度と単位（`+XX.XX oC`）を表示。
  * エラー発生時はエラー種別（`TC OPEN !` 等）を表示。
* **シリアル出力**
  * USB シリアル（9600 bps）経由で `温度, 経過時間(ms)` の形式で出力。
  * PC側のターミナルやデータ収集ソフトウェアで容易にログ保存が可能。
* **経過時間リセット機能**
  * 割り込み処理（INT4）を用いたタクトスイッチにより、チャタリングを除去しつつ経過時間をリセット。

| 電源 | USB バスパワー (DC +5V) | PC または USB 電源から供給 |

## 使い方

### 1. 準備（PC側アプリケーション）
本装置から送信されるシリアルデータを受信・保存するために、以下のいずれかのソフトウェアをご用意ください。

* **シリアルターミナルソフト**:
  * **Tera Term**, **PuTTY**, **CoolTerm** など
  * ログ取得機能（ファイル保存機能）を有効にしておくことで、CSVデータとしてそのまま保存できます。
* **Arduino IDE**:
  * 「シリアルモニタ」または「シリアルプロッタ」（グラフ描画）で簡易確認が可能です。
* **自作スクリプト等**:
  * Python（`pyserial`）等を用いてシリアルポートを監視し、自動でファイル保存やグラフ化を行う構成も適しています。

### 2. 接続と測定手順
1. 熱電対の先端（感温部）を測定対象箇所に設置します。
2. 本装置の USB（Micro-B）端子と PC を USB ケーブルで接続します。
3. PC に接続すると自動で通電し、OLED に `THERMO-LOGGER` のタイトルが表示されます。
4. 約2秒後、MAX31855 の初期化が完了すると自動的に測定が開始され、OLED に現在の温度が表示されます。
5. PC側ソフトウェアで対象のシリアルポートを開き、以下の通信条件で接続します。
   * **通信速度（ボーレート）**: `9600 bps`
   * **データビット**: `8 bit`
   * **パリティ**: `なし`
   * **ストップビット**: `1 bit`
   * **フロー制御**: `なし`

### 3. TIMER_RESET ボタンの使い方
* **機能**:
  * 測定中に基板上のタクトスイッチ（TIMER_RESET）を押すと、経過時間（タイムスタンプ）が `0`（ミリ秒）にリセットされます。
* **使用場面**:
  * 加熱試験の開始、冷却開始、試薬投入など、測定対象に変化を与えた瞬間にボタンを押すことで、その事象を起点（経過時間 = 0）としたロギングを開始できます。
* **動作仕様**:
  * チャタリング防止処理（200 ms）が組み込まれているため、1回の押下につき確実に1回のリセット動作が行われます。

## シリアル出力仕様

* **出力フォーマット**:
  ```text
  <温度(℃)>, <経過時間(ms)>
  ```
* **出力例**:
  ```text
  24.50, 1002
  24.75, 2004
  25.00, 3007
  ```
* **エラー時の出力**:
  * 断線時: `THERMOCOUPLE IS OPEN!`
  * GND短絡時: `THERMOCOUPLE IS SHORT-GND!`
  * VCC短絡時: `THERMOCOUPLE IS SHORT-VCC!`
